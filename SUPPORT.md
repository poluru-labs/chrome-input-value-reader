# Support

Thanks for using Input Value Reader.

## How to get help

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/poluru-labs/chrome-input-value-reader/issues) |
| Feature request | [GitHub Issues](https://github.com/poluru-labs/chrome-input-value-reader/issues) |
| Security vulnerability | See [SECURITY.md](./SECURITY.md) — do **not** open a public issue |
| Docs / usage questions | GitHub Issues (label `question`) or email below |

## Before opening an issue

Please include:

- Extension version (`manifest.json`)
- Chrome version
- The CSS selector you used (redact any secrets)
- Expected vs actual behavior
- Whether you loaded the unpacked `extension/` folder
